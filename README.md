# 5秒後の Windows 通知 MVP

ボタンを押すと、通知の許可後に5秒待ち、ブラウザの通知 API で Windows に通知を送ります。タブは開いたままで、別タブや別アプリを前面にしても使えます。チェックボックスがオンならページから短い音も鳴らします。

## 起動

`START_HERE.bat` をダブルクリックしてください。追加ソフトは不要です。ブラウザで <http://localhost:8000/> が自動的に開きます。黒いウィンドウは通知テスト中、閉じずに置いてください。終了するときはそのウィンドウで `Ctrl+C` を押します。

自動で開かない場合は、ブラウザのアドレス欄に <http://localhost:8000/> を入力します。PowerShell から直接起動する場合は次のコマンドも使えます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

通知を求められたら許可し、ボタンを押してから別タブまたは別アプリに切り替えます。初回は許可した時点から5秒後、2回目以降はボタンを押してから5秒後です。

## 動作条件

- Chrome または Edge など、Notifications API に対応するブラウザで動作します。
- `localhost` / `127.0.0.1` または HTTPS で開いてください。サーバー側の処理は不要です。
- ページのタブとブラウザを開いたままにしてください。タブを閉じた後の通知には、別の仕組みが必要です。
- Windows の通知設定、集中モード、ブラウザのサイト設定、音量設定によって、通知や音が抑制される場合があります。
- バックグラウンドでのタイマーはブラウザが遅らせることがあります。5秒は目安です。
